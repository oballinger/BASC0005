# Lecture slides

PowerPoint is the master. Everything else is generated from it.

```
lectures/
  pptx/ -> Google Drive .../BASC0005 QM2/2026_Lectures/pptx     (symlink, not in git)
    W02 Data.pptx ... W10 Supervised & Unsupervised Learning.pptx
    private/            decks that are never published (W01, W09-full)
  qmd/                  GENERATED by tools/sync.py; don't edit by hand
    _quarto.yml, qm2.scss   revealjs settings and theme (these two are hand-written)
    w02.qmd, img/w02/ ...   one deck per week
    private/                generated from pptx/private/, gitignored
    .sync.json              hash of each .pptx at its last sync
  tools/
    sync.py             pptx -> qmd -> html (the only command you need)
    pptx2qmd.py         the converter used by sync.py
    qa/                 screenshot / contact-sheet checks
    figures/            scripts that made some figures in the decks
    migration/          one-off scripts that built the PowerPoint masters (Oct 2026)
    .venv/              python-pptx, pypdfium2, Pillow
../docs/lectures/       rendered decks, published by GitHub Pages
../slides/wNN.qmd       website pages that embed docs/lectures/wNN.html
```

## Workflow

1. Edit the deck in PowerPoint (in `pptx/`) and save.
2. Convert, render and check:

   ```
   cd ~/BASC0005/lectures
   tools/.venv/bin/python tools/sync.py          # every deck whose .pptx changed
   tools/.venv/bin/python tools/sync.py w05      # or just one
   open ../docs/lectures/w05.html
   ```

3. Publish: `tools/.venv/bin/python tools/sync.py --push` commits `qmd/` and `docs/lectures/` and pushes,
   or commit by hand.

The deck's file name sets its slug: the first word, lower-cased (`W05 Sampling & Distributions.pptx` -> `w05`).
A new week also needs a page `slides/wNN.qmd` (copy another week's) and a chapter in `../_quarto.yml`.

## What converts natively, and what becomes a picture

Native (text you can select, sharp at any size): titles, bullets and numbering, bold/italic/links,
plain paragraphs, centred lines, tables, code (a text box set entirely in a monospace font), pictures,
two-column layouts, speaker notes. Section-header slides become `#` sections.

Anything else (charts, SmartArt, shapes and arrows, text boxes placed freely over pictures)
is kept as a picture of the whole slide, rendered by LibreOffice, so it looks like PowerPoint but
isn't searchable. If a slide you care about came out as a picture, simplify it in PowerPoint:
use the layout's placeholders, a real table, or a picture next to a text box.

Slides whose text is mostly 16pt or smaller get `.smaller` on the web.

## Rebuilding the whole site

`../build.sh` renders the book and then the decks from `qmd/`. It doesn't run sync.py, so sync first
if a .pptx changed.

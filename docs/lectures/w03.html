Automatic Identification System (AIS)

Identifying STS in AIS data

  • A simple algorithm:
  • If two or more ships
  • Spend two or more hours
  • Within 500m of each other
  • Then link them together

Satellite detections + AIS

  • 33,273 satellite detections since 2021
  • Cross-referencing the satellite detections with AIS data shows close agreement.
    • Satellite image metadata used to filter AIS data ± 24h of the time when the image was taken, within 500m of the center of the detection.
    • Draught data from AIS used to infer direction of cargo transfer
  • However, instances of disagreement between AIS + RS data are interesting…

Raster Data

Raster Data: Definition

  • Similar to a digital photograph. The entire area of the map is subdivided into a grid of tiny cells, or pixels. A value is stored in each of these cells to represent the nature of whatever is present at the corresponding location on the ground.
  • The major use of raster data involves storing map information as digital images, in which the cell values relate to the pixel colors of the image. To reproduce the image the computer reads each of these cell values one by one and applies them to the pixels on the screen.

Analytical Approaches

Arithmetic

  • Zonal Statistics
    • Vector-Vector
      • Calculate the number of vectors within another vector
        • e.g. count the number of tube stations (points) within each borough (polygon)
      • We can add attribute information;
        • E.g. calculate the average vote share in a 10km grid cell
    • Vector-Raster
      • Calculate the value of a raster within each polygon
        • e.g. Calculate the average pixel value of nighttime lights within each 10km grid cell
  • Raster math
    • Add/subtract/divide/multiply one raster by another
      • E.g. subtract nighttime lights imagery taken in 1992 from imagery taken in 2012 to see which areas have become more luminous
  • Algorithms

Regression

  • You can use spatial data to generate your own data for use in a regression
  • Using zonal statistics, you can generate a table in which each row is an areal unit (e.g. province, grid-cell, etc.)
  • But, beware of AUTOCORRELATION
    • Things that are closer together (both in space and time) have more in common than things that are farther away.
    • Statistical approaches generally assume that observations are independent.

What Is a Network?

Slide text: Networks Are Everywhere · Transport · Stations linked by track · Shipping · Vessels linked by cargo transfers · Friendship · People linked on Facebook, mapped by county · Neighbourhoods · Cross-class friendships in London · Every network is a set of nodes (things) and edges (relationships between them)

The Vocabulary

  • Node (or vertex): a thing. Edge (or link): a relationship. Degree: how many edges a node has.
  • Directed: A → B isn’t B → A. Weighted: edges have a strength or cost.

Networks as Data

  • Adjacency matrix: a 1 where two nodes are connected. Good for maths, wasteful for big sparse networks.
  • Edge list: one row per edge. This is what you’ll usually load with pandas.

A Few Hubs, Many Ordinary Nodes

The London Underground is regular: every station has 1–7 neighbours. Kerch is heavy-tailed: the median vessel has 6 transfer partners, the top 1% over 67, the busiest 115. Big bulk carriers act as hubs that many small ships load into

It’s a Small World

  • Compare with a random network with the same number of nodes and edges.
  • Paths are about as short, but clustering is ~20× higher: a ship’s partners also trade with each other.
  • Short paths + high clustering = a small world. Milgram (1967): ‘six degrees of separation’. Facebook (2016): 3.6.

Finding Communities

Communities: Clustering for Networks

  • A community: many edges inside, few between
  • Groups nodes by their connections, not their features (feature-based clustering comes in Week 10)
  • Modularity: how much denser than chance (above ~0.3 is notable)
  • Louvain (2008): merge whatever raises modularity most
  • London Underground: 9 communities (Q = 0.76). No coordinates used, yet they’re geographic
